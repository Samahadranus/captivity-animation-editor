# Captivity Animation Editor

The animation editor for Captivity Reloaded mods: pose and key enemy and player clips, paint and rig bodies, build grabs, add sounds and edit maps.

This repository only holds the program's releases. The editor checks here for a new version when it starts and updates itself when you say yes.

## Download

Get `CaptivityAnimationEditor.exe` from the [latest release](../../releases/latest).

- Windows 10 or 11. It is one file; no installer.
- If you already have the Animator Kit, put the file in the kit's `Captivity Animation Editor` folder, over the old one. Your packs and blank bodies stay as they are.
- From then on the editor updates itself: **Help > Check for Updates…**

The game, the blank bodies and the example enemies are not here. They come with the Animator Kit.

## Checking a download

Each release has an `update.json` with the program's size and SHA-256. The editor checks both before it installs an update.
